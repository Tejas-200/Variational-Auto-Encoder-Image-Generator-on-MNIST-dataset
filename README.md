# Variational Autoencoder (VAE) from Scratch in NumPy

A clean, stable implementation of a Variational Autoencoder (VAE) trained on the MNIST dataset using only raw Python and NumPy. This repository contains the bug-fixed and optimized version that addresses loss explosion issues, implements KL divergence annealing, and features a clean, modular structure.

## Bug Fixes & Optimizations

### 1. Fixed KL Divergence Gradient Sign Error
* **The Problem:** In the original implementation, the gradient of the KL Divergence with respect to $\mu$ was calculated as `dKL_dmu = -mu`. During gradient descent:
  $$\mu \leftarrow \mu - \eta \cdot (-\mu) = \mu + \eta \mu$$
  This caused the mean vector $\mu$ to grow exponentially with every single iteration. As a result, the KL divergence ($0.5 \sum \mu^2$) exploded towards infinity (reaching values like $10^{15}$).
* **The Solution:** Changed the gradient to its correct mathematical value:
  $$\frac{\partial KL}{\partial \mu} = \mu \implies \text{dKL\_dmu} = \text{mu}$$
  This successfully pushes $\mu$ towards the prior mean $0$.

### 2. Addressed Reconstruction Gradient Instability
* **The Problem:** The original gradient calculation computed the derivative of the binary cross-entropy reconstruction loss with respect to the output layer pre-activation $z_3$ by explicitly dividing by $y(1-y)$ and then multiplying by $y(1-y)$ (the sigmoid derivative). Because this gradient was clipped intermediate to this calculation, it caused severe gradient vanishing and clipping artifacts when $x_{recon}$ was near $0$ or $1$.
* **The Solution:** Handled the combination of Sigmoid and Binary Cross-Entropy (BCE) analytically. The gradient simplifies beautifully and stable-ly to:
  $$\frac{\partial L_{recon}}{\partial z_3} = x_{recon} - x$$
  Using this exact formulation completely avoids division-by-zero errors, requires no clipping at this stage, and solves gradient vanishing issues.

### 3. Added KL Divergence Annealing
* **The Feature:** To prevent "KL vanishing" or "posterior collapse" in the early phases of training, we added a linear step-based KL annealing schedule.
* **How it works:** The KL divergence loss and its corresponding gradients are scaled by a factor $\beta$ that starts at `0.0` and increases linearly to `1.0` over a configurable portion of the training steps (default is the first 50% of steps).

## Repository Structure

The project has been refactored into a clean, modular structure:

```text
VAE/
│
├── data/                    # Downloaded dataset directory (created automatically)
├── utils/                   # Helper functions directory
│   ├── __init__.py
│   ├── activations.py       # Stable sigmoid, relu, and derivatives
│   ├── losses.py            # VAE loss function (BCE + KL)
│   ├── data.py              # MNIST dataset loader & automatic downloader
│   └── visualization.py     # Training curve plotting, reconstruction, and generation
│
├── main.py                  # Main execution script (training & testing loop)
├── requirements.txt         # Core dependencies (numpy, matplotlib)
└── README.md                # This readme file
```

## Setup & Running Instructions

This project is configured to run in a Python virtual environment.

### 1. Create the Virtual Environment
Open your terminal (PowerShell / Command Prompt) in the project root directory and run:
```powershell
python -m venv venv
```

### 2. Activate the Virtual Environment
* **On Windows (PowerShell):**
  ```powershell
  .\venv\Scripts\Activate.ps1
  ```
* **On Windows (CMD):**
  ```cmd
  .\venv\Scripts\activate.bat
  ```

### 3. Install Dependencies
```powershell
pip install -r requirements.txt
```

### 4. Run the Training Script
```powershell
python main.py
```
> **Note:** The script will check if you have the MNIST dataset files locally. If they are not found, it will automatically download them from a Google Cloud mirror and extract them to the `./data/mnist` directory.

## Output Files
Upon successful execution, the script will generate and save the following visualization plots:
1. `training_curves.png`: Training loss curves (Total Loss, Reconstruction Loss, KL Divergence Loss).
2. `reconstructed_images.png`: Comparison showing original MNIST digits and their corresponding reconstructions.
3. `generated_images.png`: New digits generated by decoding random latent noise samples.
